## Что реализовано (контекст для Claude)

Алгоритм (файл `python/api/server.py`, эндпоинты `/api/color_clusters/*`):

1. Загружает `point_cloud_clean.ply` через C++ `PointCloud`
2. Конвертирует RGB → **HS** (Hue + Saturation, без Value — убирает влияние освещения)
3. **KMeans** (scikit-learn) на HS-пространстве, k кластеров (по умолчанию 10, макс 15)
4. **Слияние похожих кластеров** через union-find: если медианный RGB двух кластеров
   отличается менее чем на 25/255 — объединяем
5. Сохраняет метки в `_color_cluster_labels.npy` рядом с PLY
6. Возвращает список: `{id, color[r,g,b], count, percent}`
7. `DELETE` — убирает точки выбранных кластеров, пересчитывает нормали

Интерфейс (файл `web/js/app.js`, режим `Colors`):
- Кнопка **Анализировать** → список кластеров с цветными плашками
- **Похожие** → выделяет кластеры близкие по цвету
- **Удалить** → удаляет точки выбранных кластеров из PLY

### Промпт для Claude

```
[Прикрепи правила оформления]

Напиши раздел 1.8 «Методы цветовой сегментации облаков точек» для Главы 1 ВКР.

Контекст: в разработанной системе реализована интерактивная цветовая кластеризация
облака точек для удаления фоновых объектов (трава, стол, посторонние предметы).

Содержание раздела:

1. Задача сегментации: зачем нужно разделять облако по цвету.
   Фотограмметрическое облако содержит не только объект, но и фон —
   поверхность стола, траву, окружение. Геометрические методы (DBSCAN) убирают
   изолированные точки, но не справляются с фоном, примыкающим к объекту.
   Цветовая сегментация позволяет отделить объект от фона по визуальным признакам.

2. Цветовые пространства для кластеризации:
   - RGB: простой, но чувствителен к освещению (тени меняют все три канала)
   - HSV/HSL: разделяет цвет (H), насыщенность (S) и яркость (V/L)
   - HS без V: устойчивость к перепадам освещения при сохранении цветовой информации
   Приведи формулы перевода RGB → H и RGB → S (через max/min компоненты).

3. Метод k-средних (KMeans):
   Формула целевой функции (минимизация внутрикластерной дисперсии).
   Алгоритм: инициализация k центроидов → назначение точек → пересчёт центроидов.
   Критерий останова. Сложность O(n·k·i·d).
   Выбор числа кластеров k: метод локтя, в нашем случае k=10 с последующим слиянием.

4. Слияние похожих кластеров (post-processing):
   После KMeans кластеры с близкими медианными RGB-значениями объединяются
   через структуру Union-Find (система непересекающихся множеств).
   Порог слияния: евклидово расстояние в RGB < 25/255.
   Это снижает чувствительность к выбору k и даёт более устойчивый результат.

Формулы нумеруй по ходу главы. Академический стиль. ~2–3 страницы.
Список литературы в конце раздела:
— MacQueen J. Some methods for classification and analysis of multivariate
  observations // Proc. 5th Berkeley Symp. Math. Stat. Probab. — 1967. — С. 281–297.
— Gonzalez R. C., Woods R. E. Digital Image Processing. — 4th ed. — Pearson, 2018.
```

### Промпт для Claude

```
[Прикрепи правила оформления]

Напиши раздел 3.11 «Реализация интерактивной цветовой кластеризации» для Главы 3 ВКР.

Описывай в формате: алгоритм → формулы → фрагмент кода → результат.

РЕАЛИЗАЦИЯ (файл python/api/server.py, эндпоинт color_clusters_analyze):

1. Конвертация RGB → HS:
   Входные данные: массив точек с цветами (N, 3), значения uint8 или float [0,1].
   Формулы (приведи явно):
     max_c = max(R, G, B)
     min_c = min(R, G, B)
     delta = max_c - min_c
     S = delta / max_c  (если max_c > 0, иначе 0)
     H = зависит от доминирующего канала:
       если max=R: H = ((G-B)/delta mod 6) / 6
       если max=G: H = ((B-R)/delta + 2) / 6
       если max=B: H = ((R-G)/delta + 4) / 6
   Почему без V: перепады освещения изменяют яркость, но не оттенок и насыщенность.

2. KMeans на HS-пространстве:
   hs = np.column_stack([h, s])  # форма (N, 2)
   km = KMeans(n_clusters=k, random_state=42, n_init=10, max_iter=100)
   km.fit(hs)
   labels = km.labels_  # (N,) целые числа 0..k-1

3. Слияние похожих кластеров через Union-Find:
   Для каждой пары кластеров (i, j):
     med_i = median(RGB[labels==i])
     med_j = median(RGB[labels==j])
     если ||med_i - med_j||₂ < 25/255 → объединить через parent[find(i)] = find(j)
   Перемаркировка: labels = remap[labels], где remap[i] = find(i).
   Эффект: нечувствительность к выбору k, устойчивость к тонким цветовым вариациям.

4. Сохранение меток:
   labels_path = ply_path.parent / "_color_cluster_labels.npy"
   np.save(str(labels_path), labels)
   Метки совпадают по индексу с точками PLY (порядок не меняется).

5. Удаление кластеров (color_clusters_delete):
   keep = ~np.isin(labels, cluster_ids)
   pc.points = pts[keep]
   — аналогично обновляются нормали и цвета
   После удаления: pc.estimate_normals(k=30)

Приведи ФРАГМЕНТЫ КОДА (Python, сокращённо, с нумерацией листинга).
Формулы нумеруй. ~3–4 страницы.
Академический стиль. Не упоминай 3D-печать.
```
